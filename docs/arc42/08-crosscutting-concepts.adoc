= 08. Crosscutting Concepts

== Architecture & Domain Concepts
* Logging & Diagnostics: Standard error logging with traceback output (`dmarc-parser/main.py`, `smtp-ingester/main.py`, `api/main.py`).
* Database Session Management: SQLModel session injection via `get_session` helper (`api/main.py`).
* Data Processing: XML extraction supporting `.zip` and `.gz` report archives (`dmarc-parser/main.py`).
