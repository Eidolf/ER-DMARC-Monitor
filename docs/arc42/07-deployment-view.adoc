= 07. Deployment View

== Local / Development Deployment
* Container Orchestration: Local multi-container development environment defined in `docker-compose.yml`.
* Services:
  - `api`: FastAPI application (`api/Dockerfile`, `docker-compose.yml`)
  - `frontend`: React SPA web server (`frontend/Dockerfile`, `docker-compose.yml`)
  - `smtp-ingester`: SMTP mail receiver (`smtp-ingester/Dockerfile`, `docker-compose.yml`)
  - `dmarc-parser`: Queue worker (`dmarc-parser/Dockerfile`, `docker-compose.yml`)
  - `db`: PostgreSQL database container
  - `redis`: Redis queue broker container
